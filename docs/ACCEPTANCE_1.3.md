## What changed and how to inspect it

- Root AGENTS replaces exactly the two obsolete prose contracts: full subtitle is no longer mandatory, and quote/pattern slot selection is no longer the new drafting path. Main title/Amazon remain; author is program-signed. Other safety rules and original regression gates remain.
- `evidence.py`/Researcher stores bounded original snapshots, distinct from model bio/fit_reason. `generation.py` integrates Engine's existing generation/review entry points; `contracts.py` hard-validates complete prose and metadata. New tests explicitly reject source-ID-with-wrong-semantics through a negative independent reviewer.
- `profiles.py`, existing AI/anthropic_search/net transports: task routing, encrypted key references, Legacy migration, precise local parameter preview and call logs. Protocols never receive research tools on writing/review/reply paths. No endpoint-change key inheritance, model fallback or effort downgrade.
- `Engine.dispatch` enforces version binding in review/ai_review/automatic; manual approval requires a current check. Edits, sources, profiles/mode/footer, concurrent late reviews, stale inbound replies and attempted kind relabelling are covered.
- Assets are generated/checked/stored first, referenced by the actual offer, then delivered verbatim first in an interested reply. Missing asset/version, impossible promises and new inbound invalidate the answer. Held replies update the same inbound-linked record, preserving uniqueness and sent history.
- Worker writes operational failure fields, preserves permission text, enforces chain/tick bounds and preserves hourly polling/75-minute health. Original ten/day,61-minute minimum, default70 gap, suppression/DSN/DMARC/Reply-To/thread/two-reply/uncertainty tests still run.
- `migration4.py` and new rollback tooling cover the actual1.2/schema3 deployment baseline. Source-verification remains3; generation-contract is3; database-schema is4. These are separate version domains.
- Web stays FastAPI/Jinja2. Profiles/editable config, preview/logs, evidence/brief/assets/revision details, edit/redraft/recheck/approval and explicit manual responsibility are present. Tailscale/ports remain Compose variables.

Original mocks now supply explicit synthetic snapshots/full prose/reviewer results. Old schema assertions advance to4; source-verification assertions remain3. Old slot-parser adversarial tests remain historical helper tests, while real new-path tests cover full prose, no generic fallback, bounded rewrites and missing evidence. Safety expectations were not removed to obtain green tests.
