# 合规与安全边界

核对公开资料日期：2026-09-24。本文件是软件的风险边界，不替代适用地区的专业法律意见，也不保证任何服务商允许自动冷邮件。

## 联系与内容
- 公开邮箱不是普遍营销同意。默认仅已有许可；自动陌生拓展仅在管理员显式确认美国公开业务范围时运行，并逐个核对来源。其他地区或个人邮箱不能自动推定为可联系。
- From、主题和作者身份真实；邮件明确说明为图书阅读邀请，由作者的自动助理发送，包含真实邮寄地址和退订。
- 不买评价、不报销购书、不奖励/要求评价、不模拟读者、不给评论模板、不把开始阅读与公开评论绑定。
- 不修改价格、KDP Select、广告、商品页，不安排Free Promotion，不批量发送完整EPUB/PDF。拒绝附件是本应用的范围限制，不把所有少量章节摘录一概断言为平台绝对禁止。
- 不绕验证码、登录墙、robots拒绝、来源拒绝营销声明或反爬限制；不使用邮箱猜测、枚举或账号轮换来躲避垃圾邮件系统。
- 70分钟限频不是“过反垃圾保证”。来源、许可、内容、认证、退订与收件者投诉同样重要。

## 数据与模型
- 网站文字和收到的邮件都是不可信数据；没有通用代码执行、shell、文件读写、发送新收件人等工具授权给模型。
- 分类/问题答复只读取新来信与简短图书目录；不向模型传邮箱密码/API Key/整个历史数据库。
- 原始全文来信保存在本机数据库并设保留期限；备份包含个人资料和解密材料，必须私密保管。
- 模型与搜索服务是外部处理方：管理员必须接受其对应数据条款和费用。`store:false`不是零数据保留承诺。
- UI转义第三方文字、不渲染收到的HTML、不打开附件或远程图片、不埋打开跟踪像素。
- 来源与提供方HTTP仅使用公共HTTPS443，阻止内网/回环/链路本地及DNS混合解析，TLS按主机验证，API请求不携带密钥跟随重定向。SMTP/IMAP也只接公共主机，强制TLS，不降级明文。

## 外发和状态
- SQLite事务预占发送槽，SMTP之前写入状态，重启不清零。
- `accepted`=SMTP接受，不是送达、打开、销量、KENP或评价。
- SMTP最终响应丢失时无法通过本地事务保证真正exactly-once；应用选择不自动重发并标为uncertain，减少重复骚扰风险。
- 网页退订/后台停发入库即阻止后续队列；邮件退订受每60分钟IMAP同步影响，不能声称实时接收。已经在SMTP连接里提交的邮件无法收回。
- 不识别的From、非本系统线程、回复地址变化、缺可信DMARC等转人工。关闭DMARC会降低防伪造强度，线程匹配并非密码学验证。
- 未知或未明确报告阅读行为时保留未确认；兴趣不是阅读，普通称赞不是具体练习反馈。

## 对外部建议的限定
- “每天10封就不会进垃圾箱”不是可保证的结论；邮箱企业版也不自动允许陌生推广。务必查看实际服务商AUP，不轮换域名、伪造身份或模拟人类行为来绕过拦截。
- 换成同域名另一个邮箱地址不能隔离域名信誉。是否启用独立子域需单独评估认证/维护，不由程序自动创建。
- 美国的CAN-SPAM不只管批量邮件；真实性、商业目的披露、邮寄地址和退出均需处理。
- 不能把“欧盟=GDPR禁止、加拿大=全部绝对事前同意”当完整法律判断。区域、受众类型、数据处理、联系用途和例外需核实；本程序采取更保守的美国公开业务白名单或真实许可模式。
- 自动回信可披露自动助理身份，不加“随机10–40分钟看起来像真人”的逻辑。首封70分钟间隔是配额控制，不是反垃圾绕过措施。

## v1.2补充
- 州名/缩写按USPS资料整理，但城市+州文本只是来源信号，不是人口、实际办公地或身份认证。拒绝/冲突/历史/客户/活动线索以及单城市名进入人工核实；不能利用放宽格式绕过合法联系范围。
- 分地址或子域可方便运营管理，不保证信誉完全隔离。Gmail官方说明发送者分类等会按主域聚合子域流量；不要以为子域出问题绝不影响主域。本程序没有自动域名/邮箱轮换或仿人随机延迟来逃避过滤。
- 内部后台用SSH隧道无需公开域名；公开后台则需可信HTTPS。public_url用于公网退订，回复STOP仍可用并按小时处理，不把链接扫描当退订。
- 原生搜索工具的来源仍需程序再读网页；不执行网页、邮件或模型提出的shell/任意工具指令。只开放基础服务端搜索，不开放动态代码过滤。
