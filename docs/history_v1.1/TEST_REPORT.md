## 新增验证重点

| 风险/流程 | 实际覆盖 |
|---|---|
| 小时收信 | 121秒不重复、3599秒不重复、3600秒允许；手动任务、重启共享数据库门槛；错误只存类别，不泄漏错误体密钥。 |
| 健康耦合 | 75分钟成功有效期；已知失败/积压/解析缺口立即挡外发；未来时间戳不作为有效收信。更换邮箱后旧收信健康不复用。 |
| 大邮件/积压 | >512KB不下载；未核对UID缺口显式暂停；>50封积压下一小时继续，清完前不发送。 |
| 来源 | 精确邮箱/匹配原文/姓名/地点核对；模型单独声称US不放行；form中的no-solicitation不被删掉。 |
| MX | 正常、Null MX、无MX、NXDOMAIN、DNS超时/故障、明显不安全MX名；使用假DNS响应测试，不探测真实收件箱。 |
| 去重 | 邮箱、同业务域父子域、队列占位、365天冷却、匿名后抑制哈希；同邮箱不会到一年后重发。 |

| SMTP | 明确550地址拒绝、450临时拒绝、5.7策略拒绝、认证/DATA拒绝及超时uncertain区分；禁止自动重发。 |

## 测试变更说明

原有“150秒后收信”的测试预期改为3600秒，符合用户要求。同域名多个联系人原用于测试发送间隔，现改为不同测试业务域，避免新域名去重掩盖计时测试；域名保护另有专门测试。旧来源测试注入假DNS，不依赖测试环境外网。没有删除安全断言来凑通过。

首批10项回归测试在实现前全部失败；之后另有匿名、RCPT策略、三轮、时间、配置切换等先失败后修复的记录。红阶段文件只是历史过程，不能覆盖最终完整测试结论。
