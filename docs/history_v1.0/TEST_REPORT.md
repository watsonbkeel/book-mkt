## 2. 自动测试覆盖

- 上限10首封/日、间隔最小61分钟（默认70），发送时区与跨日边界；并发预留不超额。
- SMTP接收完成后的间隔；异常标记uncertain不自动重发；Worker恢复不重跑未决发送。
- 发送中的联系人同时退订，SMTP成功回写不能覆盖抑制状态。
- 邮箱大小写去重、已联系历史去重、历史记录不计入系统新发送。
- 实际来源邮箱、页面域名、活动摘录、地区证据验证；不采用模型猜测地址。
- 私网/本机/元数据地址拦截、混合DNS结果、重定向检查、连接绑定及响应大小上限。
- Responses网页搜索请求结构与实际搜索记录；Brave检索后实际读取页面，不仅用片段凑候选。
- IMAP首次只建游标、UID去重、UIDVALIDITY变化重建、超大邮件限制与只读抓取。
- Message-ID线程匹配、Reply-To更换、DMARC验证、自动通知及机器人回复循环防护。
- 纯文本和HTML引用分离；旧邮件页脚中的STOP不会冒充新退订；主题STOP+空正文也能停发。
- 永久退信须与实际发送记录匹配；陌生来信不自动跟进；每联系人回复次数上限。
- 明确有兴趣不变为已经阅读；计划阅读不变为实际开始；负面实际体验也是反馈。
- 登录、CSRF、配置秘密不回显、HTML内容转义、CSV公式注入防护、匿名退订路径。
- 真实时间范围统计；邮件导出包括实际发送时正文与页脚；不从点击推断订单/KENP。
- 私有备份、SHA核验、新空目录恢复、恢复暂停、密钥不匹配拒绝。
- 模拟完整流程：来源→首封→感兴趣来信→Chapter15推荐回复→STOP停发。

## 4. 必须在你的环境确认

使用`上线前真实服务验收.md`，先完成自己控制的邮箱之间的闭环。以下当前均为未验证：

1. 实际API Key是否有gpt-6-luna权限，第三方网关是否实现选定的Responses/web_search接口，Brave密钥是否有效。
2. 真实SMTP身份授权、服务商允许用途、SPF/DKIM/DMARC、收件域接受/垃圾箱情况。
3. IMAP应用密码/安全方式、实际Authentication-Results信任域、服务商旧邮件与文件夹规则。
4. 服务器安装与镜像拉取、磁盘权限、端口、证书、SSH隧道、公网退订回调。
5. 真实检索结果的适用性、发信地域与许可、真实业务邮箱、明确拒收声明。

发送间隔不保证送达、法律合规或模型输出完全正确。默认暂停、范围核验与异常转人工降低风险，但不能替代发件责任人。没有独立外部安全审计，也没有真实读者结果。
